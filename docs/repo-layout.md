# Repo layout

```
packages/
  shared/src/index.ts              wire types: Cell, PuzzleMeta, GridSnapshot,
                                   ClientMessage, ServerMessage
  server/
    src/
      index.ts                     Fastify app; opens sqlite + runs migrations;
                                   hydrates in-memory store from puzzles+boards;
                                   serves static client + SPA fallback in prod
      db.ts                        node:sqlite handle + migration runner (PRAGMA
                                   user_version); migrations[] is append-only
      importer.ts                  importPuzzle() (CLI use) + insertPuzzleRow()
                                   (shared INSERT/UPDATE) + slugify()
      boards.ts                    findOrCreateBoard / addBoardMembership /
                                   getBoardState / listBoards (pure DB ops;
                                   no in-memory side effects)
      auth.ts                      scrypt password hashing, handle validation,
                                   session row helpers; pure primitives
      authRoutes.ts                Fastify auth surface: onRequest session
                                   middleware (resolves req.user from the
                                   crossplay_session cookie) + /api/auth/*
                                   routes (register / login / logout / me)
      http.ts                      registers every /api/* route (auth gates
                                   on req.user; share + leave routes branch
                                   off boards_users)
      format.ts                    parser-picker for .puz vs .ipuz inputs
                                   (extension + content-sniff); shared by
                                   the CLI importer and upload route
      shutdown.ts                  graceful shutdown: drain dirty boards,
                                   close Fastify, close DB
      fillPercent.ts               computeFillPercent(initial, current): null when
                                   live equals initial (NEW), else 0–100 used by
                                   the home page meta line
      puzzle.ts                    parses .puz buffer to PuzzleState + solution;
                                   rejects rebus via IpuzUnsupportedError
      ipuz.ts                      reads + writes .ipuz JSON; rejects (does not
                                   degrade) unsupported features via
                                   IpuzUnsupportedError
      store.ts                     in-memory cache of active boards: lazy
                                   loaded on first WS connect; mutations mark
                                   `dirty` and (re)start a 15s idle flush
                                   timer; flushAndEvict on last-socket-close;
                                   flushAll on SIGTERM/SIGINT
      ws.ts                        WebSocket route /ws/boards/:id + handlers
                                   + heartbeat
      types/puzjs.d.ts             ambient types for the untyped puzjs lib
    tsconfig.build.json            emit-to-dist config for `npm run build`
    data/                          sqlite db lives here (gitignored)
    fixtures/
      a-very-moth-puzzle.puz       Joel's own puzzle (committed for dev)
      sunday-sample.puz            21x21 synthetic, generated by the script below;
                                   carries circle / shading / multi-letter rebus /
                                   very-long clue
      sunday-sample.ipuz           same grid with everything in the .puz plus a
                                   given letter, a Schrödinger cell, and a dozen
                                   null cells cut from the corners (features the
                                   .puz format has no slot for); exercises the
                                   .ipuz code path
    scripts/
      make-sunday-fixture.mjs      regenerate both sunday fixtures (.puz + .ipuz)
      set-puz-note.mjs             patch a .puz description in place
      puz-to-ipuz.ts               convert .puz files to .ipuz JSON
                                   (file-to-file converter, no DB)
      import-puzzle.ts             import a .puz/.ipuz into the puzzles table
                                   (run via `npx tsx`)
  client/
    public/
      icon.svg                     standalone site icon (also inline as SiteIcon)
    src/
      App.tsx                      route + load-state + header + feedback bar
      routing.ts                   hand-rolled SPA routing (NO react-router)
      api.ts                       REST helpers; throws HttpError(status)
      useBoardSocket.ts            ws connection w/ auto-reconnect + handler bag
      cursor.ts                    pure cursor + clue navigation; tested
      chatIdentity.ts              account handle (authed) | persisted Rando<NN> (anon); palette
      feedback.ts                  Feedback type (id, text, level, autoVanishMs?)
      puzzleActions.ts             type for the actions the menu invokes
      linkify.tsx                  URL auto-link helper for chat messages
      previewText.ts               first-line/length-cap helper for ChatPreview
      relativeTime.ts              friendly date ladder (just now / Nm / Nh /
                                   yesterday / N days / Mon D / Mon D, YYYY)
      draggablePanel.ts            useDraggablePanel hook (Rect + load/save/clamp)
                                   shared by ChatPanel and NoteDialog
      components/
        Panel.module.css           shared card/header/dragHandle/close (composed
                                   into ChatPanel + NoteDialog modules)
        Board.tsx + Cell.tsx       grid render; sized via inline font-size + em.
                                   Board exports NARROW_QUERY (consumed by
                                   PuzzleView; the @media rules in App and
                                   PuzzleView CSS modules must stay in sync)
        RebusInput.tsx             inline overlay input for rebus entry,
                                   absolute-positioned by Board over the
                                   focused cell (em-sized)
        ClueList.tsx               across/down lists; click to position
        Menu.tsx                   dropdown opened by clicking the title
        ModeButton.tsx             pen/pencil toggle in the header (P button)
        SiteIcon.tsx               inline SVG of the site icon
        LandingPage.tsx            anon home route: hero + login + signup +
                                   invite-code paragraph; honors ?return=
        HomePage.tsx               authed home route: hero + Puzzle library
                                   + Your games + Upload sections, each with
                                   a client-side filter input
        ShareDialog.tsx            modal opened from the board menu's
                                   "Share with…"; accumulates result lines
                                   for multiple shares in one session
        UploadForm.tsx             multipart upload — creates a board (no puzzle
                                   row); navigates to /b/<boardId>
        NoteDialog.tsx             draggable/resizable notes panel (react-rnd)
        HelpDialog.tsx             centered modal with shortcuts + pen/pencil
                                   and rebus explanations; opened by `?` or
                                   the Help menu item
        NumberJumpDialog.tsx       small popup opened by `#`; user types a
                                   clue number, Enter jumps the cursor there
        ChatPanel.tsx              draggable/resizable chat panel (react-rnd)
        ChatIndicator.tsx          fixed top-right chat bubble + unread badge
        ChatPreview.tsx            3-second preview of latest chat over the header
        FeedbackBar.tsx            colored pill in header slot; replaces clue when set
        PuzzleView.tsx             owns cursor + snapshot + ws + chat/notes state
        PrintPage.tsx              /b/:id/print route: two buttons that
                                   lazy-import ../print and open Blobs
      print/
        index.ts                   re-exports generateCrosswordPdf,
                                   generateSolutionPdf
        generator.ts               puzzle PDF entry (title + grid + clues)
        solution.ts                solution PDF entry (filled grid; meta.note
                                   flows through the clue regions)
        layout.ts                  pure region geometry, no jsPDF refs
        title.ts                   title block draw (Times)
        grid.ts                    grid draw (Helvetica); preserves numbers,
                                   circles, shading, given, rebus shrink,
                                   edge marks
        clues.ts                   ACROSS/DOWN flow + pagination (orphan rule
                                   keeps a heading with its first clue)
        fonts.ts                   font name + size constants
```
